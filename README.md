# ESP32-C3 RC Controller

ESP32-C3、ブラウザ、Web Bluetooth を使用した簡易RCカーコントローラーです。スマートフォンやPCのブラウザから左右・前後の操作値を送信し、モーターとステアリングサーボをBLE経由で制御します。

## 構成

```text
.
├── RCController.ino  # ESP32-C3側ファイル
└── docs/
    ├── index.html    # ブラウザ操作画面
    └── app.js        # Web Bluetoothとスティック操作
```

## 構成部品

- ESP32-C3
- Mini L298Nモータードライバ
- ステアリング用サーボモーター
- 72 x 40 ピクセル SSD1306 OLED（I2C）
- モーター用電源
- 配線、コネクタ等

> モーターとサーボには、ESP32-C3のGPIOへ直接大電流を供給せず、モータードライバと適切な電源・電圧・共通GNDを使用してください。

## ピン配置

| 対象 | GPIO |
|---|---:|
| モーター IN1 / 前進 | 3 |
| モーター IN2 / 後退 | 4 |
| ステアリングサーボ | 7 |
| OLED SDA | 5 |
| OLED SCL | 6 |

Mini L298NはENA端子を使用せず、IN1とIN2へ直接PWMを出力します。

## OLED表示

OLEDには以下を表示します。

```text
BLE:OK / BLE:WAIT / BLE:OFF
FB:+  0
LR:+  0
M:+  0 S: 90
```

- `BLE:OK`: BLE接続中かつ操作データを受信中
- `BLE:WAIT`: BLE接続中だがフェイルセーフ状態
- `BLE:OFF`: 未接続
- `FB`: 前後操作値
- `LR`: 左右操作値
- `M`: モーターPWM。正が前進、負が後退
- `S`: サーボ角度

## 必要なライブラリ

Arduino IDEで以下のライブラリをインストールしてください。

- ESP32Servo
- U8g2 Library

また、ESP32 Arduino Core 3.x、およびESP32 BLEライブラリが利用できるボード設定が必要です。

## 書き込み手順

1. Arduino IDEでESP32-C3のボードを選択します。
2. `RCController.ino` を開きます。
3. 必要なライブラリをインストールします。
4. ボードとシリアルポートを選択します。
5. 書き込みます。
6. シリアルモニターを115200 bpsで開くと、BLEの状態を確認できます。

起動時のBLEデバイス名は `ESP32C3-RC` です。

## ブラウザ操作画面

ブラウザ操作画面は `docs/index.html` です。

Web Bluetoothの制約により、通常は次の環境で起動してください。

- HTTPS環境
- `http://localhost` または `http://127.0.0.1`
- Chrome系ブラウザなどWeb Bluetoothをサポートするブラウザ

ローカルで確認する例:

```sh
cd docs
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000
```

GitHub PagesなどHTTPSでホストする場合は、リポジトリの `docs` フォルダを公開用ディレクトリに指定すると利用できます。

## 操作方法

1. ESP32-C3に電源を入れます。
2. ブラウザで操作画面を開きます。
3. `BLE 接続` を押します。
4. 一覧から `ESP32-C3-RC` を選択します。
5. 左のスティックで前進・後退、右のスティックで左右を操作します。
6. スティックを離すと前後・左右とも中央の0へ戻ります。

スティック操作はPointer Eventsを使用するため、タッチ操作にも対応します。

## BLE通信仕様

| 項目 | 値 |
|---|---|
| デバイス名 | `ESP32C3-RC` |
| Service UUID | `12345678-1234-5678-1234-56789abcdef0` |
| Characteristic UUID | `12345678-1234-5678-1234-56789abcdef1` |
| 送信形式 | 2バイトの符号付き8ビット値 |
| 送信周期 | 40ms（25Hz） |

データ形式:

| バイト | 内容 | 範囲 |
|---:|---|---|
| 0 | 左右（LR） | -100から100 |
| 1 | 前後（FB） | -100から100 |

- LRが正: 右
- LRが負: 左
- FBが正: 前進
- FBが負: 後退

ESP32側でも値は-100から100に制限されます。

## フェイルセーフ

ESP32-C3は、以下のいずれかの場合にモーター停止とステアリング中央化を行います。

- BLEが未接続
- 操作データ未受信
- 最終受信から300ms以上経過

モーター停止時は、モータードライバのIN1とIN2へ最大PWMを出すブレーキまたは両方0V相当のフリー状態を選択できます。

## ユーザー設定

`RCController.ino` 冒頭の設定値を変更できます。

| 設定 | デフォルト | 内容 |
|---|---:|---|
| `STEERING_MAX_ANGLE` | 20 | 中央からのステアリング最大角度 |
| `STEERING_CENTER` | 90 | サーボ中央角度 |
| `STEERING_REVERSE` | false | ステアリング方向反転 |
| `MOTOR_REVERSE` | false | モータ方向反転 |
| `MOTOR_DEADZONE` | 3 | 停止扱いとする操作値 |
| `MOTOR_MIN_PWM` | 0 | 回転開始時の最低PWM |
| `MOTOR_BRAKE_ON_STOP` | false | trueで停止時ブレーキ、falseでフリー |
| `BLE_TIMEOUT` | 300 | フェイルセーフまでの時間（ms） |

モーターが低速で唸るだけで回らない場合は、`MOTOR_MIN_PWM` を40〜80程度に調整します。

## PWM設定

デフォルトのモータPWM設定は次の通りです。

- 周波数: 20kHz
- 分解能: 8ビット（0〜255）

発熱や駆動力低下がある場合は `PWM_FREQ` を10000または5000に変更できます。

## 注意事項

- モーター用電源とロジック用電源を適切に接続してください。
- サーボの電源電圧、モーター電圧、ドライバの定格を確認してください。
- 初回テスト時はモーターを車体から浮かせたり、タイヤを阻止したりして安全に動作確認してください。
- BLE切断時や通信途絶時は、フェイルセーフが正しく動作することを確認してください。
